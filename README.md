# Adventní bitva

Jednoduchá tahová hra (1 vs 1 proti počítači). Celá hra je v `index.html`, obrázky jsou ve složce `images/`.

## Nasazení na GitHub Pages
1. Nahraj obsah této složky (`index.html`, `images/`) do repozitáře na GitHubu.
2. Repozitář → **Settings → Pages** → *Build and deployment*: **Deploy from a branch**, větev `main`, složka `/ (root)`.
3. Za minutu se objeví adresa `https://<tvoje-jmeno>.github.io/<repozitar>/` – otevři ji v mobilu.

## Úprava statů
Nahoře v `index.html` je blok `CHARACTERS` (životy, útok, obrany na startu a maximum), `BAR_MAX`, `AI` (chování soupeře) a `T` (rychlost animací).
